# Security

This is a localhost-only test target with public demo credentials, not a production service. Postman CLI is the default runner. Optional Newman compatibility has unresolved dependency advisories and is not installed by default. Reports include synthetic tokens and must not be reused with confidential systems without an artifact policy.

Do not disclose sensitive vulnerability details in public issues. Use GitHub's private vulnerability reporting option when available; otherwise ask the maintainer to arrange a private channel without posting the details.
